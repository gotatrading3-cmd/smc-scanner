# Données automatiques — GOTA Signaux

Cette branche est écrite **uniquement** par le workflow « GOTA Signaux » (GitHub Actions).

- `signals_state.json` : état courant (signaux actifs, dernière bougie traitée…)
- `signals_history.jsonl` : **historique de chaque signal clôturé, pertes incluses**

Chaque commit est horodaté publiquement : le passé ne peut pas être réécrit sans que cela se voie.
Ce n'est pas un conseil financier. Le trading comporte un risque de perte en capital.
